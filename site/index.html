Why Margin

Simple on the surface. All of calibre underneath.

calibre can do almost anything with e-books, and shows almost all of it at once. Margin keeps the power and puts the window in order, so the thing you came to do is the thing you see.

01

Intuitive first

A clear library with a preview of the book you picked, filters you can read at a glance, and a toolbar that shows what you use. Press Ctrl+K to find any action or setting by name.

02

No feature left behind

Converting formats, sending to your reader, editing metadata, the e-book viewer and editor, the content server, news and plugins: all of calibre, unchanged underneath.

03

Installs beside the others

Margin has its own folder, settings and Start menu entry. It never replaces calibre or Calibre Zen, and the same library opens in any of them.

04

English and Hebrew

Fully translated into Hebrew, with the whole window laid out right to left: toolbars, menus, columns and dialogs, not only the words.

05

Made for your reader

The list of books on your device shows the columns your library does. Send in the format you prefer, and update a book that is already on the device in place.

06

Handy tools built in

A jobs panel in the status bar, Goodreads Updater and Book Cleanup included, and in-app updates that check this project's releases.

Calibre Zen Margin

Why “Margin”? The margin is where a reader leaves a mark of their own beside somebody else’s text. The work of those who came before stays in the middle; this is a note beside it.

Download

Get Calibre Zen Margin

Free, for Windows 10 and 11, macOS and Linux. Each version is listed here as soon as it is released.

Windows says it protected my PC

The installer is not signed with a paid certificate yet, so SmartScreen may warn about it. Click More info, then Run anyway. The SHA-256 next to each file lets you check that the download is the one published here.

macOS says the app can’t be opened

The Mac build is not notarized by Apple yet. Drag the app to Applications and open it once; when macOS refuses, open System Settings › Privacy & Security and click Open Anyway. After that it opens normally.

Installing on Linux

Download the install script and run sh install-zen.sh --latest: it fetches the archive for your processor, checks it and unpacks it into a calibre-zen-margin folder. Or install the Flatpak with flatpak install --user calibre-zen-margin-*.flatpak.

Questions

Good to know

Will it change my calibre or Calibre Zen?

No. Margin installs into its own folder with its own settings, so calibre, Calibre Zen and Margin can all be installed at once. Your library is just a folder: you can open the same one in any of them, one at a time.

Do my plugins work?

Yes. Underneath, Margin is the calibre release it is built on, so plugins that work there work here. On first start you can bring over your calibre settings and plugins, or start fresh.

Which calibre is it built on?

Each release says which calibre version it is based on, and new calibre releases are merged in regularly.

How does it update?

The app checks this project’s releases and offers to download and install a new version for you. You can also always download it from this page.

Is it free?

Yes, and open source under the GNU GPL v3, like calibre and Calibre Zen. The source is on GitHub.
